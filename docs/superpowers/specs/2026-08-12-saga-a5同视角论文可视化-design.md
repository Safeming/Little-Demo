# SAGA 与 A5 同视角论文可视化设计

## 目标

生成可直接用于论文主文的 SAGA-Canonical 与 A5 真实语义编辑对照图。图像比较必须与现有严格测试协议一致，不使用测试掩码参与编辑选择，也不通过人工调参或挑选视角改变结论。

## 比较范围

- 对象固定为 `CoreView_377`、`CoreView_386`、`CoreView_394`，按该顺序排列。
- 编辑部位固定为 `hair` 与 `shoes`。
- 方法固定为 `SAGA-Canonical B4` 与冻结的 `A5`。
- 编辑任务使用统一的颜色替换：hair 为红色，shoes 为紫色。
- 每个方法和部位均匹配相对于 B1 参考目标响应的 `60%` 保留率。
- 相机、帧、检查点、背景、渲染器与编辑参数在方法间保持一致。

## 公平性约束

1. SAGA 使用验证集选定的 B4 读出和阈值，不在测试图上重新调阈值。
2. A5 使用冻结的 LOSO 配置和对应对象的冻结 bank，不在测试图上重新选择配置。
3. 60% 保留率通过屏幕空间目标区域编辑响应匹配得到各方法的编辑强度，不把 bank 权重简单乘以 0.6。
4. 测试 parser mask 仅用于计算指标和强度匹配，不用于约束或合成最终编辑图。
5. 所有最终图片均为同一个 3DGS rasterizer 的真实编辑渲染，不使用掩码着色或后处理覆盖模拟结果。
6. 固定主图不依据测试效果挑选视角；精选图必须明确标为客观精选，不能替代固定主图。

## 渲染流程

### 阶段一：强度扫描

在严格测试集的 9 个视角上，对 SAGA 和 A5 扫描统一强度网格。对每个对象、方法和部位汇总屏幕空间目标编辑响应，选择最接近 B1 满强度目标响应 60% 的强度。若离散网格精度不足，在相邻强度间进行确定性的局部细化，最终记录实际保留率、可达性和所选强度。

### 阶段二：真实编辑渲染

使用阶段一得到的对象-方法-部位强度，渲染所有 9 个严格测试视角。每个视角保存：

- 输入 RGB；
- SAGA hair 编辑；
- A5 hair 编辑；
- SAGA shoes 编辑；
- A5 shoes 编辑；
- 对应的屏幕空间编辑指标。

### 阶段三：图版合成

固定主图统一使用 `c22_f000420`。采用每对象一行的 B 布局：

| 行 | Input | Hair / SAGA | Hair / A5 | Shoes / SAGA | Shoes / A5 |
|---|---|---|---|---|---|
| 1 | CoreView_377 | | | | |
| 2 | CoreView_386 | | | | |
| 3 | CoreView_394 | | | | |

图版保持原始纵横比，采用统一裁剪范围与字号，不在人物上叠加指标文本。指标和选择依据保存在伴随 CSV/JSON 中。

## 客观精选规则

精选目录在每个对象的 9 个严格测试视角内选择一个共同视角，该视角同时用于 hair 和 shoes，避免同一行拼接不同姿态。

排序规则如下：

1. 对每个视角、方法、部位计算 `outer_delta_sum / target_delta_sum`，得到归一化泄漏；目标区域响应为零的候选视角排除。
2. 对 hair 和 shoes、SAGA 和 A5 的归一化泄漏取平均，越低越优。
3. 若平均泄漏相同，则平均目标区域 IoU 越高越优。
4. 若仍相同，按视角名称字典序选择，确保结果确定可复现。

精选目录保存所选图、全部候选排名 `selection_ranking.csv` 和规则说明。目录名包含 `objectively_selected`，论文中必须说明这是按预先声明规则选出的展示图。

## 输出结构

根目录：

`exp/acceptdata/saga_a5_same_view_paper_visual_20260812/`

包含：

- `fixed_main/`：固定视角主图、无标注单帧、带列/行标签的 PNG 与 PDF；
- `objectively_selected/`：客观精选主图、对应单帧和排名清单；
- `subjects/CoreView_*/`：强度扫描、9 视角渲染、逐视角指标和 provenance；
- `summary.json`：输入资产指纹、固定协议、最终强度、实际保留率和产物路径；
- `README.md`：论文使用说明、图注草稿和公平性声明。

## 实现边界

- 优先扩展 `tools/render_semantic_real_editing_paper_suite.py` 对 SAGA bank 的支持，复用已有权重解析、真实编辑和指标实现。
- 新增独立的 SAGA/A5 可视化编排脚本，负责强度匹配、视角排序、调用渲染器和图版合成。
- 图版合成使用 Pillow，同时输出无损 PNG 和矢量 PDF。
- 不修改训练结果，不覆盖既有 A5/SAGA 评测目录，不改动任何用户已有实验资产。

## 异常处理

- bank 点数、检查点点数或协议指纹不一致时立即停止。
- 60% 目标响应不可达时停止该对象生成，并在汇总中明确记录，不静默降低目标。
- 严格测试视角缺失或目标掩码为空时从候选精选中排除；固定视角缺失则整个任务失败。
- 输出前检查 NaN、空白渲染、图像尺寸、文件数量以及方法间输入 RGB 一致性。

## 测试与验收

1. 单元测试覆盖 SAGA B4 权重解析、强度匹配、确定性视角排序和 B 布局合成。
2. 三个对象均有 9 个视角的两方法、两部位真实编辑输出。
3. 每个对象、方法、部位的实际目标保留率接近 0.60，容差由强度细化网格决定并写入汇总。
4. 固定图严格使用 `c22_f000420`，行顺序严格为 377、386、394。
5. 精选图的每个对象只有一个共同视角，且可由排名 CSV 第一行复现。
6. PNG 非空、尺寸一致、人物区域存在有效像素；PDF 可正常生成。
7. provenance 明确记录未使用测试 parser 进行编辑选择或后处理合成。
