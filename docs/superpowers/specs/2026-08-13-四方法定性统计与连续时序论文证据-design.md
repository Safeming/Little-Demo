# 四方法定性图、统计显著性与连续时序论文证据设计

## 目标

为 CoreView 377、386、394 上已经完成的 A5、SAGA-Canonical、Gaussian Grouping-Canonical 和 SG-GS-Released-Code-Canonical 外部对比补齐三类可直接进入论文的证据：

1. 相同视角、相同冻结操作点下的真实编辑定性图；
2. 保留被试与相机相关结构的配对统计显著性结果；
3. 三被试、三测试相机、三个动作阶段上的连续 21 帧时序稳定性表和曲线。

本任务不修改已有训练结果，不重新选择 bank，不根据测试结果重新调阈值，也不覆盖现有严格测试目录。

## 冻结实验范围

### 被试与模型

- 被试顺序固定为 CoreView 377、386、394。
- 每名被试的四种方法共享同一个 40k avatar checkpoint。
- A5 使用 `frozen_a5_five_subject_main_20260723` 中对应被试的冻结 bank、LOSO 配置和操作点。
- SAGA 使用 `saga_canonical_five_subject_20260812_120625_bjt` 中对应被试的冻结 B4 bank、阈值和操作点。
- Gaussian Grouping 使用 `gaussian_grouping_canonical_three_subject_20260813_0958_bjt` 中对应被试的冻结 B4 bank、阈值和操作点。
- SG-GS 使用 `sggs_released_code_canonical_three_subject_20260813_formal` 中对应被试的冻结 B4 bank、LOSO 阈值和操作点。
- SG-GS 的论文名称必须保留 `Released-Code-Canonical controlled-input adaptation`，不得表述为官方完整系统的原生复现。

### 操作点

- 主比较统一使用相对于 B1 的 Gaussian 点激活 `target retention = 0.60`。
- 操作点从既有冻结 `matched_retention.csv` 唯一解析，编辑强度在定性图和整段时序中保持固定。
- 不用测试 RGB 响应、测试 parser mask或逐帧结果重新拟合强度。
- Gaussian Grouping 在 CoreView 377 无法达到 60% retention，因此：
  - 定性图使用其最大可达 40% 操作点并标记 `GG†`；
  - 60% 定量表把该项记录为不可达；
  - A5 与 GG 的 60% 配对推断只使用共同可达的 386、394；
  - 不把 377 的 40% 结果混入 60% 均值或显著性排名。

## 统一数据流

### 标准长表

四种方法必须导出同一字段结构的逐帧、逐部位长表。每行由以下主键唯一确定：

`subject, camera, frame, anchor, window, method, part, retention`

每行至少包含：

- `target_activation`
- `outer_activation`
- `actionable_outer_activation`
- `raw_leakage_ratio`
- `actionable_leakage_ratio`
- `iou`
- `boundary_f1`
- `target_empty`
- `valid_part`
- bank、checkpoint、协议和操作点指纹

逐帧聚合时，leakage 使用激活量先求和再取比值，不能直接平均六个部位的比值；Macro mIoU 和 Boundary F1 只对有效且非空目标部位求平均，同时输出有效部位计数。

### 公平性约束

1. 四种方法共享相机、帧、parser mask、边界半径、背景、rasterizer 和评价代码。
2. Gaussian 点权重由冻结 bank 和冻结阈值确定，整个测试序列不变。
3. 测试 parser mask只用于指标计算和预先声明的客观视角排序，不参与 Gaussian 选择、编辑权重或图像后处理。
4. 所有随机统计固定 seed；输出记录 bootstrap 和置换次数。
5. 输入或指纹不一致时停止，不能静默回退到其他 checkpoint、bank、阈值或视角。

## 定性图设计

### 固定版式

采用已确认的方案 A，输出 Hair 和 Shoes 两张独立 `3 x 5` 图：

| 行 | Input | SAGA | Gaussian Grouping | SG-GS | Ours |
|---|---|---|---|---|---|
| CoreView 377 | | | `GG†` | | |
| CoreView 386 | | | | | |
| CoreView 394 | | | | | |

- 行顺序固定为 377、386、394。
- 列顺序固定为 Input、SAGA、Gaussian Grouping、SG-GS、Ours。
- Hair 和 Shoes 使用同一个被试视角，防止按部位分别挑姿态。
- 输出 PNG 和 PDF，并另存每个无标签单帧。
- 图内不叠加小数指标，指标进入伴随 CSV 和图注。
- `GG†` 的图注必须说明 CoreView 377 为最大可达 40%，其他方法和被试为 60%。

### 视角选择

固定主图和客观精选图同时保留：

- 固定主图沿用 `c22_f000420`，不根据效果挑选。
- 客观精选仅在既有 9 个严格测试视角内进行，且同一被试的 Hair 和 Shoes 共用一个视角。
- 对每个候选视角，先计算四方法、两部位的有效归一化 leakage，再以预先声明的综合排序选择；GG-377 使用其已声明的 40% 特例。
- 排序键依次为平均 actionable leakage、平均目标 IoU 的相反数、视角名称，确保确定性和可复现性。
- 精选图目录和图注明确包含 `objectively selected`，不能替代固定主图的无偏展示地位。

## 统计显著性设计

### 比较对象

- A5 对 SAGA：377、386、394。
- A5 对 SG-GS：377、386、394。
- A5 对 Gaussian Grouping：仅 386、394 的共同 60% 可达样本。
- 主指标为 actionable leakage；raw leakage、Macro mIoU 和 Boundary F1 作为共同报告的次指标。

### 效果量与区间

每个比较输出：

- A5 和外部方法的估计值；
- 配对绝对差 `A5 - baseline`；
- 对 leakage 指标的相对降低率；
- 配对中位差；
- 每名被试的独立效果；
- 被试分层 bootstrap 95% CI。

bootstrap 固定为 20,000 次。每次先有放回抽样被试，再在每个被试内有放回抽样相机，最后在相机内有放回抽样测试帧。该区间用于描述当前测试层级下的效果不确定性，不宣称三名被试代表总体人群。

### 配对置换检验

- 使用双侧配对符号翻转置换。
- 交换块固定为 `subject-camera`，同一相机的三个严格测试帧整体翻转方法标签。
- 三被试比较有 9 个交换块，枚举全部 `2^9 = 512` 种符号组合。
- GG 的共同可达比较有 6 个交换块，枚举全部 `2^6 = 64` 种符号组合。
- 检验统计量为块均值的平均配对差。
- 同一指标内 A5 对三个外部方法的 p 值使用 Holm 校正；同时保存原始 p 值。
- 若离散精确检验的最小可达 p 值不能低于 0.05，结果必须如实报告，不使用逐帧独立假设制造显著性。

### 论文措辞边界

统计结论限定为“在当前测试被试、测试相机和冻结协议下呈显著或一致改善”。三名被试不足以支持面向总体人群的强泛化声明；显著性表必须与逐被试效果表一起呈现。

## 连续时序设计

### 窗口

- 测试相机固定为 c21、c22、c23。
- 锚点固定为 180、420、540。
- 每个锚点取 `[anchor - 10, anchor + 10]`，共 21 个逐帧连续样本。
- 每名被试有 9 个窗口、189 个相机帧；三名被试合计 27 个窗口、567 个相机帧/方法。
- 窗口之间互不重叠。
- 数据加载阶段必须验证每个视角都存在；任一缺帧即停止并输出具体缺失主键。

### 帧级指标

对每帧汇总六个 compact part，得到：

- `Actionable Leakage_t`
- `Raw Leakage_t`
- `Macro mIoU_t`
- `Boundary F1_t`
- `valid_part_count_t`

目标为空的部位不记作完美预测或完美稳定，而是排除并记录有效计数。

### 窗口级稳定性

每个 `subject-camera-anchor-method` 窗口输出：

- 水平质量：21 帧均值与标准差；
- 平均相邻变化：`mean(abs(x_t - x_(t-1)))`；
- 最坏局部波动：20 个相邻变化的 95 分位数；
- 有效帧和有效部位计数。

主时序表以 27 个窗口为统计单元，报告窗口指标的均值和标准差。A5 对外部方法的时序差值按窗口配对，并使用被试分层 bootstrap 给出 95% CI。GG-377 的 40% 结果单列展示，不进入 60% 排名。

### 指标边界

本设计不使用未经光流、人体表面对应或相机运动补偿的像素帧差作为 flicker 指标，因为真实人体运动会污染该量。论文使用“temporal metric stability”或“连续帧指标波动”，不把它扩大表述成感知视频无闪烁证明。

### 可视化

- 每个指标输出按帧连续曲线，方法颜色固定。
- 曲线按被试和相机分面，锚点窗口用间隔区分。
- 对每种方法输出预先固定关键窗口的 contact sheet，帧顺序严格递增。
- 补充材料保存完整 27 窗口的机器可读明细；主文只放聚合时序表和一张代表性曲线。

## 实现结构

### 代码边界

- 新增四方法论文证据编排器：解析冻结输入、操作点、定性图和总 provenance。
- 新增独立统计模块：读取标准长表，计算分层 bootstrap、块置换、Holm 校正和论文表。
- 扩展现有严格评测或真实编辑渲染入口，使其接受显式视角列表并导出逐视角 leakage 激活量；不改变已有聚合公式和默认行为。
- 新增时序队列脚本：先运行 canary，再按 377、386、394 顺序运行完整窗口。
- 新增验收器：检查输入指纹、主键唯一性、帧数、有限数值、方法顺序、图像尺寸和冻结操作点。

### Canary

完整队列前先运行：

- CoreView 377；
- c21；
- 170–190；
- A5、SAGA、Gaussian Grouping、SG-GS；
- 固定 bank、阈值和操作点。

Canary 必须证明：84 个方法帧全部完成、逐帧主键一致、数值有限、参数未改变、显存可接受、预计完整队列时间有记录。失败时不启动正式队列。

## 错误处理

以下情况必须立即失败：

- checkpoint、bank 或协议文件缺失；
- bank 点数与 checkpoint Gaussian 点数不一致；
- 冻结阈值或操作点行缺失、不唯一或超出合法范围；
- 非 GG-377 项无法达到 60% retention；
- GG-377 最大可达项不是冻结主表记录的 40%；
- 连续窗口存在缺帧、重复主键或帧顺序错误；
- 四方法的共同 parser target、边界半径或输入 RGB 不一致；
- 任一指标出现 NaN/Inf；
- 图像为空、尺寸不一致、人物被裁断或标签重叠；
- bootstrap、置换或 Holm 输出无法由相同 seed 重现。

## 测试策略

实现采用 TDD，至少覆盖：

1. 由锚点生成 21 帧窗口，检测越界、缺帧和重复帧；
2. 从冻结主表唯一解析 60% 操作点以及 GG-377 的 40% 不可达特例；
3. 逐部位激活量正确聚合为逐帧 leakage；
4. 空目标部位不进入 Macro mIoU、Boundary F1 和稳定性均值；
5. 分层 bootstrap 固定 seed 可复现且保持被试/相机层级；
6. `subject-camera` 块符号翻转得到正确精确 p 值；
7. Holm 校正满足单调性并保持方法映射；
8. 相邻绝对变化和 95 分位数计算正确；
9. GG-377 不进入 60% 配对统计；
10. Hair/Shoes 图严格保持三行五列、固定方法顺序、`†` 标记和非空输出；
11. provenance 指纹、帧数和主键完整性检查能拒绝篡改或缺失产物。

## 验收标准

1. Canary 通过后才启动完整时序队列，并记录训练无关、只读评测的运行时间和峰值显存。
2. 两张固定视角和两张客观精选 Hair/Shoes 图均有 PNG/PDF，视觉检查无空白、裁断或标签重叠。
3. 严格测试显著性长表覆盖 3 被试 x 3 相机 x 3 帧 x 4 方法 x 有效部位，GG-377 特例可追溯。
4. 时序长表覆盖每种方法 567 个相机帧，窗口表覆盖每种方法 27 个窗口；GG-377 40% 状态单列。
5. 主表、逐被试表、时序表、曲线、contact sheet、协议和完整性报告全部非空并通过验收器。
6. 数值能从原始长表重新计算，固定 seed 重跑得到相同统计结果。
7. 专项测试、相关既有严格协议测试和语义真实编辑测试全部通过；任何历史基线测试缺口单独披露，不写成全量仓库测试通过。

## 论文使用边界

完成这些产物后，可以声称 A5 在冻结 60% retention 操作点下，相比三类外部方法具有更低空间泄漏，并在当前三被试连续窗口上表现出更小或更一致的指标波动，但最终措辞必须由实际 CI 和置换结果决定。不得在结果生成前预设“显著”，不得把 GG-377 的 40% 图混作 60% 比较，也不得把 SG-GS controlled-input adaptation 写成官方原生复现。
