# 渲染边界颜色精修 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不破坏当前 3DGS 部件语义和 Editor bundle 的前提下，补一版可泛化的边界/颜色精修训练，让渲染边缘更清楚、前景颜色更接近原图，并用量化指标判断是否值得替换当前查看版本。

**Architecture:** 当前 `v395_dense_canary_semantic` 是语义 adapter-only 训练，`position_lr/opacity_lr/scaling_lr/feature_lr/texture_lr` 都为 0，所以 RGB 变糊不是 label bank 主因。下一版把语义参数冻结，单独开一个短程 render-quality refine：只允许颜色特征、边界 opacity residual、可选极小 scale residual 学习，并关闭 densify 和 semantic loss。先加诊断脚本做 before/after 对比，再加可复用 launcher，最后通过 render 指标和截图决定是否生成新的 viewer bundle。

**Tech Stack:** Bash launcher, Python 3, NumPy, OpenCV, Pillow, unittest, existing `train.py`, `render.py`, `tools/analyze_377_render_contours.py`, `tools/semantic_viewer/build_part_label_bank.py`.

---

## Root Cause Summary

当前问题分成两类：

1. **语义识别杂乱/连接处泄露**
   - 当前最推荐 Editor bundle 是：
     `/remote-home/ming/3dgs-avatar-release-main/exp/acceptdata/viewer_bundle_v395_dense_canary_semantic_face_lowerguard_reliability_neighborfill_20260609`
   - `part_label_bank.npz` 已经不是 2D mask voting 主来源，而是来自 `binding_compact_semantic_probs_asset`，并经过 `confidence/margin/reliable_mask/editable_label/neighbor_fill_mask` 后处理。
   - 主要剩余歧义集中在 `upper/lower/skin` 边界，不是 face 全身误标。

2. **渲染边缘发糊/颜色略暗**
   - 当前渲染目录：
     `/remote-home/ming/3dgs-avatar-release-main/exp/acceptdata/v395_dense_canary_semantic_20260609_export/test-view/renders`
   - 已检查 `results.npz`：PSNR 约 `33.20`，SSIM 约 `0.9995`，LPIPS 约 `0.02268`。
   - 视觉上边缘软、黑背景 halo 明显、前景均值略低于原图。
   - 根因是 v395 只训练语义 adapter；RGB/opacity/scale/position 没有动，所以它不会修复底层 splat 边界和颜色。

本计划只修第二类“渲染边界/颜色质量”，并保持第一类语义链路稳定。

Implementation requirements:

- Accept RGB arrays in either `uint8 [0,255]` or float `[0,1]`.
- Build `boundary_band` from the GT foreground mask using dilation minus erosion.
- Compute:
  - `foreground_l1`
  - `boundary_l1`
  - `interior_l1`
  - `boundary_minus_interior_l1`
  - `gt_mean_luma_fg`
  - `render_mean_luma_fg`
  - `render_minus_gt_luma_fg`
  - `halo_luma_outside`, measured on a dilated outside ring around the GT mask
  - `edge_symmetric_dist_px`
  - `hard_score = boundary_l1 + 0.015 * edge_symmetric_dist_px + 0.25 * halo_luma_outside`
- CLI arguments:
  - `--render-dir`
  - `--gt-template`, for example `data/ZJUMoCap/CoreView_377/{cam}/{frame:06d}.jpg`
  - `--mask-template`, for example `data/ZJUMoCap/CoreView_377/{cam}/{frame:06d}.png`
  - `--out-dir`
  - `--band-width`
  - `--topk`
- Parse filenames matching `render_c(?P<cam>\d+)_f(?P<frame>\d+).png`.
- Write `render_quality_summary.json` and `render_quality_samples.csv`.

Create `tools/formal/render_quality_refine_compare_v1.sh`:

```bash
#!/usr/bin/env bash
set -euo pipefail

ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/../.." && pwd)"
cd "$ROOT"

PYTHON_BIN="${PYTHON_BIN:-/opt/miniconda3/envs/ictrl/bin/python}"
DATA_ROOT="${DATA_ROOT:-$ROOT/data/ZJUMoCap}"
SUBJECT="${SUBJECT:-CoreView_377}"
BEFORE_RENDER_DIR="${BEFORE_RENDER_DIR:-$ROOT/exp/acceptdata/v395_dense_canary_semantic_20260609_export/test-view/renders}"
AFTER_RENDER_DIR="${AFTER_RENDER_DIR:?set AFTER_RENDER_DIR to refined test-view/renders directory}"
RUN_ID="${RUN_ID:-render_quality_compare_v1_$(TZ=Asia/Shanghai date '+%Y%m%d_%H%M%S_bjt')}"
OUT_DIR="${OUT_DIR:-$ROOT/exp/acceptdata/${RUN_ID}}"

mkdir -p "$OUT_DIR/before" "$OUT_DIR/after"

"$PYTHON_BIN" tools/analyze_render_quality_edges.py \
  --render-dir "$BEFORE_RENDER_DIR" \
  --gt-template "$DATA_ROOT/$SUBJECT/{cam}/{frame:06d}.jpg" \
  --mask-template "$DATA_ROOT/$SUBJECT/{cam}/{frame:06d}.png" \
  --out-dir "$OUT_DIR/before" \
  --band-width 7 \
  --topk 12

"$PYTHON_BIN" tools/analyze_render_quality_edges.py \
  --render-dir "$AFTER_RENDER_DIR" \
  --gt-template "$DATA_ROOT/$SUBJECT/{cam}/{frame:06d}.jpg" \
  --mask-template "$DATA_ROOT/$SUBJECT/{cam}/{frame:06d}.png" \
  --out-dir "$OUT_DIR/after" \
  --band-width 7 \
  --topk 12

"$PYTHON_BIN" - "$OUT_DIR" <<'PY'
import json
import sys
from pathlib import Path

out_dir = Path(sys.argv[1])
before = json.loads((out_dir / "before" / "render_quality_summary.json").read_text(encoding="utf-8"))
after = json.loads((out_dir / "after" / "render_quality_summary.json").read_text(encoding="utf-8"))

keys = [
    "mean_foreground_l1",
    "mean_boundary_l1",
    "mean_interior_l1",
    "mean_edge_symmetric_dist_px",
    "mean_render_minus_gt_luma_fg",
    "mean_halo_luma_outside",
    "mean_hard_score",
]
delta = {}
for key in keys:
    delta[key] = after.get(key, 0.0) - before.get(key, 0.0)

report = {
    "before": before,
    "after": after,
    "delta_after_minus_before": delta,
    "acceptance_hint": {
        "boundary_l1_should_drop": delta["mean_boundary_l1"] < 0,
        "foreground_l1_should_not_increase_more_than_0_003": delta["mean_foreground_l1"] <= 0.003,
        "halo_should_drop_or_stay": delta["mean_halo_luma_outside"] <= 0.0,
        "hard_score_should_drop": delta["mean_hard_score"] < 0,
    },
}
(out_dir / "compare_summary.json").write_text(json.dumps(report, indent=2), encoding="utf-8")
print(json.dumps(report["delta_after_minus_before"], indent=2))
PY

echo "COMPARE_OUT_DIR=$OUT_DIR"
```

## Generalization Notes

这版不会过度绑定当前人物，原因是：

- 诊断脚本按 `render_cXX_fXXXXXX.png`、GT template、mask template 工作，不依赖 377 的特殊语义类别。
- refine launcher 的 `SUBJECT/DATA_ROOT/BASE_EXP/BASE_CKPT/TRAIN_VIEWS_SPEC/TRAIN_FRAMES_SPEC` 都可通过环境变量覆盖。
- 训练不加入人工手写的“头、裤子、鞋子”局部规则；它只根据 RGB foreground、boundary L1、edge/perceptual 约束改善渲染。
- 语义资产冻结，不把本次颜色/边界修复混进 label bank 语义判断。

风险：

- 如果换成新人物，但 base checkpoint 本身几何/opacity 很差，短程 refine 只能小幅改善，不能替代完整几何训练。
- 如果 foreground mask 本身边界有错，boundary loss 会跟着错误 mask 学习。
- 如果学习率过大，可能让边缘锐化但脸/手细节变脏；所以第一版必须 conservative，不开 densify。
