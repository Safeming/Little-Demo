# 结构化可解释可编辑 Avatar 推进计划

记录时间：2026-05-10

## 当前目标

当前项目目标不是单纯追求更清晰的 Avatar renderer，而是实现：

```text
构建一种结构化、可解释、并且最终可编辑的人体 Avatar 表示。
```

论文主线建议表述为：

```text
基于显式绑定的结构化 Avatar 表示，
在统一表示中联合建模运动层级、细粒度区域语义与区域级外观资产，
并支持后续的语义导出与编辑。
```

因此后续推进不应继续无限期卡在 StageA/A2 清晰度小修上，而应围绕下面三层结构补齐闭环：

```text
底层：稳定运动与粗结构
中层：body / cloth / compact semantic
上层：fine Hulk editable assets
```

## 为什么不建议直接改成底层全细粒度

Hulk 细分割很有价值，但不应直接替代底层 binding。原因：

```text
1. 细粒度 parser 是 2D pseudo-label，边界和遮挡噪声大。
2. 同一 3D 点在多视角下可能被 Hulk 分成不同细类。
3. 细语义和运动绑定不是同一层级：
   face / arm / hand / leg 都属于 body parent，但运动骨骼不同；
   upper / lower / shoes 属于不同可编辑资产，但底层仍需要稳定运动和粗结构。
4. 如果底层完全由 Hulk 细类主导，论文贡献容易被理解成 parser-driven labeling，
   反而削弱显式绑定的创新点。
```

推荐主线：

```text
底层保持显式绑定和粗结构稳定；
中层学习 body / cloth / compact semantic；
上层导出 fine Hulk editable assets。
```

flat fine-grained bottom-level 可以作为小规模 ablation，而不是主工程主线。

## StageB-light 目标重新定义

StageB-light 不负责修 RGB 清晰度。它的目标是：

```text
在当前最稳 RGB base 上，
轻量接回 Hulk/parser，
把细粒度 2D parser pseudo-label 蒸馏到显式绑定 3D 表示中，
提升 body / cloth / compact semantic 的可分性，
并证明不伤主渲染。
```

建议以 `v215c ckpt109410` 作为当前 RGB base。

StageB-light 初版不应大幅开放：

```text
Gaussian xyz；
scale；
opacity；
主 RGB texture；
pose correction；
camera affine / camera geometry。
```

StageB-light 初版允许训练：

```text
compact semantic head / adapter；
body-cloth semantic adapter；
必要的极小范围 binding semantic parameters。
```

### Step 3：实现 StageB-light semantic loss

需要补齐或确认的 loss：

```text
L_body_cloth_parser:
  rasterized body_prob / cloth_prob 对齐 Hulk-derived body / cloth mask。

L_compact_parser:
  rasterized compact_semantic_probs 对齐 compact 6 类 mask。

L_parent_consistency:
  fine/compact labels 聚合后与 body / cloth parent 一致。

L_exclusive:
  body 与 cloth 避免高置信重叠。

L_temporal_or_neighbor_smooth:
  约束语义资产不要在邻近点/相邻帧上碎裂。

L_rgb_guard:
  RGB render 指标不允许明显退化。
```

监督区域应排除：

```text

人体边界 5-15px；
极小面积 label；
遮挡严重区域；
多视角冲突明显区域；
手臂/衣服交界的低置信区域。
```

## 当前问题判断与后续修复路线

当前状态：

```text
语义可编辑主线：
  v233d 已经基本达成 StageC 所需的 3D compact semantic 输出。
  hair/face/skin/upper/lower/shoes 都有可用连续区域。

剩余语义问题：
  - lower 偶发肩颈/上身小块误识别；
  - upper 背心边缘少量漏分；
  - shoes recall 中等，仍非论文级；
  - face 边界略宽。

新暴露的边缘问题：
  - RGB render 的人体 silhouette 仍有破损/锯齿/低 opacity 残留；
  - binding map 的边缘破碎一部分是导出 mask threshold，一部分继承 RGB/opacity 支撑；
  - v234 证明只动 opacity residual 不足以修掉。
```

关键判断：

```text
1. 当前不应把“边缘破损”归因成 StageB compact semantic 没做好。
   v233d 的 compact semantic 分类已经比前序版本大幅稳定；
   edge 破损是另一个层面的 silhouette / opacity / geometry support 问题。

2. StageC 可以继续基于 v233d 做真实 3D semantic edit loop。
   为了 demo 稳定，StageC asset 导出应使用 softer export：
   lower opacity threshold + close kernel 5 + compact confidence 不硬裁。

3. 如果要论文级视觉质量，需要单独做 silhouette/support refine，
   但不能只做 600 step opacity residual 小探针。
```

下一步建议分两条线推进：

```text
线 A：StageC 闭环优先
  目标：证明 3D compact semantic 可以稳定驱动 hair/face/skin/upper/lower/shoes 编辑。

  做法：
    1. 固定 checkpoint 为 v233d final：
       exp/stageB/377_hulk_light_v233d_shoes_preserve_control_stageB_compact_v233_skincloth_20260512_161652_bjt/ckpt135710.pth

    2. StageC 导出统一使用 softer export 参数：
       compact_semantic_opacity_threshold 0.025 左右；
       close kernel 5；
       semantic_editable_compact_confidence_threshold 0.0；
       保留 opacity-normalized compact prob。

    3. StageC 编辑展示先聚焦：
       hair / face / skin / upper / lower 的 region cutout 和颜色/透明度编辑；
       shoes 暂时作为可用但非主卖点。

  理由：
    当前 semantic 主问题已收敛，继续追 RGB silhouette 会拖慢 StageC 闭环。
```

```text
线 B：单独 silhouette/support 修复
  目标：修 RGB render 和 binding map 共同继承的破损边缘。

  v234 失败原因推断：
    1. 只允许 opacity 与 boundary_opacity_residual 学习，表达能力太弱；
    2. boundary_aware_freeze_converter_for_boundary_loss=true，
       对 converter / geometry / support 的修正能力很有限；
    3. boundary_scaling_residual_lr=0，无法调整边缘 Gaussian footprint；
    4. densify 禁用，缺失边缘无法长出新支撑点；
    5. loss 只看 hard mask opacity，容易修不动真实颜色边缘与遮挡混合。

  推荐下一版 v235 设计：
    1. 仍从 v233d final 出发，但只做 silhouette/support，不动 semantic logits；
    2. 开启小幅 boundary_scaling_residual_lr，例如 1e-5 到 3e-5；
    3. opacity_lr 提到 1e-4 级别，boundary_opacity_residual_lr 提到 5e-5 级别；
    4. 将 boundary_aware_boundary_opacity_residual_scale 提到 1.0；
    5. 保留 texture frozen，但允许 boundary scaling residual 修 footprint；
    6. 针对 outer false positive 与 inner false negative 分开统计：
       shrink 修外凸碎边，grow 修缺口/断边；
    7. 训练步数至少 2k-4k，小步验证，不直接长训；
    8. 每 500 step 渲染 held-out quick contour，对比：
       mean_boundary_l1、edge_symmetric_dist、top_hard_contours。

  风险：
    - scaling residual 太强会让轮廓变胖或局部糊；
    - densify 如果打开，可能破坏当前 v233d 的语义稳定性；
    - 用 parser/hard mask 直接压轮廓，会引入 2D parser 边界偏差。
```

```text
线 C：语义小修，不与 silhouette 混在一起
  目标：在 v233d 基础上只处理 compact semantic 的局部误识别。

  优先级：
    1. lower 肩颈/上身小块误识别 suppression；
    2. upper 背心边缘少量漏分；
    3. shoes recall；
    4. face 边界。

  原则：
    不要在同一个实验里同时大改 semantic prior 和 RGB silhouette。
    否则结果不好时无法判断是语义逻辑退化，还是 opacity/geometry 改坏。
```

当前推荐决策：

```text
短期：
  v233d final 作为 StageC 主 checkpoint；
  softer export 作为 StageC demo/export 默认；
  不使用 v234 作为主模型。

中期：
  开一个 v235 silhouette/support 小分支，只修 RGB/opacity 边缘；
  开一个独立 v236 compact semantic 小分支，只修 lower 小块误识别和 shoes recall。

论文叙事：
  StageB compact semantic 已经证明从 2D parser 蒸馏到稳定 3D compact 部件；
  silhouette 破损属于 avatar 重建质量/opacity support 问题，不应混进 semantic editable 的主贡献里。
```
