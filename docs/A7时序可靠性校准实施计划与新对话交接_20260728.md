# A7 时序可靠性校准实施计划与新对话交接

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不重训 Avatar 主干、不引入逐帧状态的前提下，把冻结 A5 扩展为静态 canonical A7 语义资产，降低姿态变化造成的 screen-space outer/boundary flicker，同时守住 A5 的空间泄漏、覆盖率、语义精度和重建质量。

**Architecture:** A7 先在固定 calibration camera/frame 上累计每个 Gaussian/part 的可见性、target/outer footprint 波动和 boundary crossing，再对 A5 `soft_edit_weights` 做静态可靠性衰减，并通过确定性的 target-preserving water-filling 把缺失 target mass 重分配给稳定 carrier。所有超参数只在 donor subjects 的 c17-c20 validation 上按 LOSO 选择；c21 仅作回顾性测试，c22-c23 和未触碰主体用于冻结确认。

**Tech Stack:** Python 3、NumPy、PyTorch/CUDA、现有 Gaussian renderer、JSON/NPZ、argparse、pytest、Bash。
