## 5. 下一步最高优先级：先解决 B1 强于 B5

这是当前论文最重要的新问题。

推荐不要继续单独压 semantic probability，而是把 B1 的强多视角 ownership 作为输入证据：

```text
voting posterior / vote count
  + trained semantic probability
  + confidence / margin
  + footprint evidence
  + target/support decomposition
```

建议实现连续 voting posterior，而不是只保留 B1 hard label：

```text
per_part_votes / visible_vote_count
  -> voting probability
  -> confidence and entropy
  -> evidence-calibrated target/support weights
```

新的方法目标应是：

```text
至少在 retention 0.5 和 0.6 上，
B5 actionable leakage <= B1，
同时 mIoU 与 B1 的差距不超过 1-2 个百分点。
```

若做不到，应改变论文定位：

```text
主贡献从“最优 target/support 方法”
改为“严格的 Gaussian Avatar 编辑可靠性协议、资产 schema 和权衡分析”。
```

后一定位更诚实，但主会方法创新强度会下降。

## 7. 需要纳入相关工作的近期方法

以下方法会影响论文定位或 baseline 讨论：

1. Gaussian Grouping：静态 3DGS identity encoding、分割和局部编辑。
   https://arxiv.org/abs/2312.00732

2. SG-GS：将人体语义属性和 semantic projection/regularization 引入 Gaussian Avatar。
   https://arxiv.org/abs/2408.09665

3. GaussianEditor：Gaussian semantic tracing 与局部编辑。
   https://arxiv.org/abs/2311.14521

4. GaussianAvatar-Editor：面向 animatable Gaussian head avatar 的文本编辑和时空一致性。
   https://arxiv.org/abs/2501.09978

5. AvatarBrush：可动画 Gaussian Avatar 的局部纹理和几何编辑。
   https://arxiv.org/abs/2511.19189

6. DAMA：利用 2D segmentation 构建 body-anchored multi-layer Gaussian avatar，并强调 clean garment separation。
   https://arxiv.org/abs/2605.21001

7. AvatarMix：Gaussian Avatar 服饰组合、身份保持和接缝修复。
   https://arxiv.org/abs/2606.03506

实验上最值得适配的是：

```text
Gaussian Grouping 风格的 persistent identity baseline；
SG-GS 风格的 semantic attribute baseline；
B1 multi-view voting；
```

AvatarBrush、GaussianAvatar-Editor、DAMA 和 AvatarMix 的任务设定不完全相同，至少需要在 related work 和能力对比表中说明边界；如果代码和数据允许，再做定性或子任务对比。
