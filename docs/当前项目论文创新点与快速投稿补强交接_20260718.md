## 1. 一句话结论

当前项目最适合发表的主线不是：

```text
把 CoreView_377 的 PSNR / LPIPS 调到某个历史 checkpoint。
```

而是：

```text
面向可动画 3D Gaussian Avatar 的持久语义绑定、
多视角证据校准和低泄漏可靠局部编辑。
```

推荐论文定位：

```text
Reliable Part Editing for Animatable Gaussian Avatars
via Evidence-Calibrated Persistent Semantic Binding
```

中文概括：

```text
基于多视角证据校准与持久语义绑定的
可动画 Gaussian Avatar 可靠部件编辑
```

当前已经具备方法原型和第一主体结果，但还不能直接宣称形成了稳投主会的完整证据。主要缺口是跨主体、标准语义指标、matched-retention 对比和强 baseline。

---

## 2. 当前论文真正解决的问题

普通 3DGS Avatar 已经能完成高质量渲染、姿态驱动、实时动画和新视角合成，但通常没有直接解决：

```text
每个 Gaussian 属于哪个人体或服饰部件；
部件语义能否随动画持久存在；
跨视角、跨姿态后的编辑选择是否一致；
编辑上衣、头发、鞋子时是否泄漏到皮肤或其他部件；
如何在减少泄漏的同时保留足够的目标区域。
```

推荐研究问题：

```text
如何将人体部件语义绑定到可动画 Gaussian Avatar 的 canonical primitives，
并利用语义置信度、多视角 footprint evidence 和边界支持关系，
生成跨视角、跨姿态稳定且低泄漏的局部编辑选择？
```

这不是单纯的人体分割问题，也不是通用静态 3DGS 编辑问题，而是动态 Avatar 的持久语义资产与可靠编辑问题。

## 3. 可以写进论文的三个主要创新点

### 3.1 Persistent Semantic Gaussian Asset

从多视角人体 parser supervision 中学习每个 canonical Gaussian 的部件概率：

```text
face, hair, upper, lower, shoes, skin
```

语义不是临时附着在某张 2D 图像上，而是作为 Gaussian 资产的一部分保存在 canonical/binding 空间中，并随 Gaussian deformation 进入不同姿态和视角。

主要资产字段：

```text
semantic_probs
part_label
editable_label
confidence
semantic_margin
reliable_mask
soft_edit_weights
edit_target_weights
edit_support_weights
```

关键实现：

```text
models/deformer/rigid.py
  binding_compact_semantic_probs
  binding_compact_semantic_probs_asset

utils/part_label_bank.py
  finalize_trained_semantic_probs()
  compute_semantic_margin()
  compute_semantic_reliable_mask()
```

可以宣称：

```text
为可动画 Gaussian Avatar 构建可导出、可复用、可编辑的持久部件语义资产；
语义与 canonical Gaussian 绑定，不依赖每个新视角重新执行局部选择；
为跨姿态局部编辑提供稳定的 primitive-level ownership。
```

不能单独宣称：

```text
首次为 Gaussian 加语义；
首次使用 2D mask 监督 Gaussian semantics；
首次进行 Gaussian 局部编辑。
```

相关工作已经覆盖部分基础能力：

- Gaussian Grouping：Gaussian identity encoding、分割和编辑，https://arxiv.org/abs/2312.00732
- SG-GS：可动画人体 Gaussian semantic attributes、2D semantic projection 和 neighborhood consistency，https://arxiv.org/abs/2408.09665
- GaussianEditor：Gaussian semantic tracing 与局部编辑，https://arxiv.org/abs/2311.14521

因此 per-Gaussian semantics 只能作为基础模块，不能作为整篇论文唯一创新。

### 3.2 Evidence-Calibrated Target/Support Edit Weights

这是当前最有价值、最应该重点写的方法贡献。

基础 soft edit 不再只使用：

```text
editable_label == target_part
```

而是构造连续权重：

```text
soft_edit_weight[target]
  = semantic_probability[target]
  * confidence_factor
  * semantic_margin_factor
  * reliability_factor
```

对应实现：

```text
utils/part_label_bank.py::compute_soft_edit_weights()
```

随后统计每个 Gaussian 在多视角中的 footprint evidence：

```text
footprint_target_ratio
footprint_outer_ratio
adjacent_part_ratio
view_support_count
conflict_ratio
center_outer_ratio
boundary_role_ratio
```

再进行目标保护与外泄惩罚：

```text
保留稳定命中目标区域的 Gaussian；
降低跨视角持续命中非目标区域的 Gaussian；
区分真正外泄和合法相邻边界支持；
避免只通过删除大量目标点来获得低泄漏。
```

关键实现：

```text
utils/part_label_bank.py::compute_evidence_calibrated_soft_edit_weights()
utils/part_label_bank.py::compute_footprint_distilled_soft_edit_weights()
utils/part_label_bank.py::compute_footprint_boundary_confidence_weights()
tools/calibrate_evidence_soft_edit_weights.py
```

系统还将选择拆为：

```text
edit_target_weights
  真正执行颜色、纹理、透明度或几何编辑的目标点；

edit_support_weights
  用于边界过渡、结构支持和合法相邻关系的支持点。
```

对应实现：

```text
utils/part_label_bank.py::compute_support_aware_edit_weights()
```

人体服饰边界不是简单的二元前景/背景。上衣与皮肤在袖口相邻，上衣与裤子在腰部相邻，鞋子与裤腿相邻，头发与脸部在发际线相邻。可靠编辑需要区分目标区域、允许的边界支持和真正不可接受的外泄。

### 3.3 Footprint-Aware Editing Reliability Protocol

这是第二个较强的论文贡献，但必须与标准指标配套使用。

一个 Gaussian 的椭圆 footprint 可能同时覆盖目标区域、相邻部件、边界带和真正非目标区域。只比较 Gaussian center 或 per-point label，不能真实衡量编辑会影响哪些像素。

当前系统显式计算：

```text
center leakage
footprint leakage
boundary leakage
allowed-adjacent leakage
actionable leakage
target activation
target retention
multiview mean/std/CV
```

关键实现：

```text
tools/analyze_projected_soft_edit_leakage.py
tools/analyze_multiview_semantic_consistency.py
tools/make_semantic_edit_render_preview.py
```

当前推荐主指标：

```text
boundary-tolerant actionable footprint clean
clean = 1 - soft_footprint_actionable_leakage_ratio
```

合理的论文表述：

```text
提出一个面向 Gaussian 编辑行为的 footprint-aware reliability protocol，
同时报告目标激活、原始外泄、相邻边界外泄和 actionable 外泄，
避免仅用 primitive label accuracy 高估实际编辑可靠性。
```

必须避免：

```text
94.54% clean 高于其他方法的 80% mIoU；
94.54% clean 等价于 94.54% segmentation accuracy；
boundary radius 越大说明模型越准确。
```

## 5. 当前最严重的论文风险

### 5.1 只有一个正式主体

完整闭环主要来自 CoreView_377，不足以证明方法对不同服装、体型、发型和遮挡结构有效，也不能证明当前规则没有围绕 377 手工拟合。

最低要求：再补 1 个主体。

推荐要求：总共至少 3 个主体，并且不修改方法参数。

### 5.2 自定义指标需要标准指标支撑

审稿人会质疑 allowed adjacent parts、boundary radius 和容忍区域是否人为提高了结果。

必须同时报告：

```text
mIoU
boundary IoU / boundary F1
raw footprint leakage
actionable footprint leakage
target activation retention
```

并提供：

```text
boundary radius = 0/2/4/6 sensitivity
固定的人体通用 adjacency graph
```

### 5.3 低泄漏伴随 target activation 降低

根据现有 `per_part.csv` 汇总：

```text
aggregate soft footprint target activation
/ aggregate hard footprint target activation
≈ 43.11%
```

soft 权重是连续值，hard 权重是二值，不能直接解释成丢掉 57% 目标区域，但它仍是论文风险。审稿人会追问泄漏降低是否主要来自编辑强度或覆盖率下降。

不能只报告 threshold=0.2 的单点，必须画：

```text
x-axis: target activation retention / target coverage
y-axis: raw or actionable leakage
```

在 matched target retention 或 matched edit strength 下比较：

```text
hard label
raw semantic probability
confidence soft weight
evidence-calibrated target/support weight
```

### 5.4 calibration/evaluation 数据泄漏风险

多视角 footprint evidence 不能使用最终 test cameras 的 parser mask，再在同一批 cameras 上报告提升。

正式协议必须拆分：

```text
training cameras:
  semantic training / evidence calibration

validation cameras:
  threshold 和超参数选择

held-out test cameras:
  最终 leakage、mIoU、boundary 和 edit 指标

held-out poses:
  跨姿态泛化
```

如果当前 bank 使用了 test-view evidence，正式实验必须重新生成无泄漏版本。

### 5.5 规则可能过度拟合 CoreView_377

当前方法包含 allowed adjacent pairs、boundary radius、region support、part-specific calibration 和历史 guard。论文中需要收敛为：

```text
固定的人体语义拓扑图；
主体无关的统一阈值；
由 evidence 自动决定的 target/support 权重；
不针对特定 frame、camera、subject 调参。
```

### 5.6 正式语义资产主要依赖历史 v395

最快解决方式不是继续追求更高渲染分数，而是：

```text
1. 将语义编辑方法表述为 backbone-agnostic；
2. 在一条命令 from-zero checkpoint 上重跑至少一个正式结果；
3. 在其他主体使用相同、可复现的 Avatar backbone；
4. v395 只作为历史参考或额外高质量结果，不作为唯一依赖。
```

当前 from-zero same-30 最好候选：

```text
FG_LPIPS=0.1261183470
FG_PSNR =21.8957710
```

v395 same-30：

```text
FG_LPIPS=0.1273224292
FG_PSNR =22.1020915
```

from-zero LPIPS 已足以作为论文底座，剩余 PSNR 差距不应继续阻塞语义编辑论文。

## 6. 与相关工作的边界

### 6.1 Avatar reconstruction

3DGS-Avatar 已经提供 deformable Gaussians、实时动画和 unseen-pose regularization：

```text
https://arxiv.org/abs/2312.09228
```

不能把使用 3DGS 表示人体、non-rigid deformation、实时 rendering 或一般 pose-driven animation 当作新贡献。

### 6.2 Gaussian semantics

Gaussian Grouping 已完成通用场景 Gaussian grouping、segmentation 和 local editing；SG-GS 已完成 semantics-embedded animatable human Gaussians，并用语义辅助重建和 topology。

当前项目的差异必须明确为：

```text
不是为了用 semantics 提升 reconstruction；
而是把 semantics 变成持久、可靠、可导出的编辑资产；
重点优化和评估实际 edit leakage、retention 和 multiview consistency。
```

### 6.3 Gaussian Avatar editing

相关工作：

```text
GaussianEditor: https://arxiv.org/abs/2311.14521
AvatarBrush:    https://arxiv.org/abs/2511.19189
FaceParts:      https://arxiv.org/abs/2605.13853
```

当前项目应该强调：

```text
全身固定人体语义部件；
跨姿态持久 Gaussian ownership；
多视角 evidence calibration；
target/support 编辑权重；
footprint-aware leakage-retention evaluation。
```

## 7. 推荐论文主张

推荐 Introduction/Abstract 主张：

```text
Existing Gaussian avatar methods provide photorealistic rendering and animation,
but lack persistent and reliable part-level editability.

We introduce a persistent semantic asset for animatable Gaussian avatars and
an evidence-calibrated target/support weighting scheme that converts noisy
per-Gaussian semantics into reliable editing primitives.

We further propose a footprint-aware evaluation protocol that measures actual
screen-space edit leakage, target retention, and multiview consistency.
```

推荐贡献列表：

```text
1. A persistent part-semantic asset for animatable Gaussian avatars that remains
   attached to canonical primitives across views and poses.

2. An evidence-calibrated target/support edit representation that combines
   semantic uncertainty, multiview footprint evidence, boundary roles, and
   support topology for low-leakage local editing.

3. A footprint-aware reliability protocol that jointly evaluates edit leakage,
   target retention, boundary behavior, and multiview stability.

4. Extensive evaluations across multiple subjects, views, poses, parts, and
   editing operations, showing improved leakage-retention trade-offs while
   preserving reconstruction quality.
```

第四项只有补齐实验后才能写。

## 11. From-zero 训练在论文中的位置

From-zero 训练不是这篇论文最强创新，但有三个辅助价值：

```text
1. 证明 semantic editing pipeline 不依赖历史私有 checkpoint；
2. 提供一条命令可复现 Avatar backbone；
3. 证明加入 semantics/editability 后不牺牲 reconstruction quality。
```

64k neutral、carrier state、hard compression、anchor teacher、continuous pose 等大量实验适合放 supplementary/analysis，不是主论文贡献。

## 21. 更新后的论文创新点判断

### 21.1 创新点一：Persistent Semantic Gaussian Asset

当前五主体、held-out camera、连续 570-frame 动画证明同一 canonical Gaussian selection 可以随 deformation 重复使用，不需要在每帧重新运行 parser 选择。这支持“persistent semantic asset”和“canonical primitive ownership”。

但 screen-space soft IoU 和 matched flicker 没有全面改善，因此该创新应表述为：

```text
persistent and reusable semantic binding
```

而不是：

```text
provably drift-free temporal semantic tracking
```

### 21.2 创新点二：Evidence-Calibrated Edit Reliability

这是当前最强、证据最完整的方法创新：

```text
A4 voting posterior
  -> A5 footprint evidence calibration
  -> 五主体 hard ownership/boundary 提升
  -> matched-retention leakage 显著降低
  -> recolor/removal/texture 可达记录均降低 burden
```

A4-A5 消融、五主体 LOSO 和真实编辑三条证据相互一致。论文方法标题和贡献列表应重点突出：

```text
evidence-calibrated persistent semantic editing
accuracy-constrained leakage control
```

### 21.3 创新点三：Coverage-Aware Footprint Editing Protocol

评测协议已经从早期单一 clean ratio 演进为：

```text
无 test calibration 泄漏；
公平共享 renderer；
标准 mIoU/boundary/micro/soft IoU；
matched target retention；
reference-normalized pooled burden；
per-subject/per-part coverage constraint；
subject-level paired bootstrap；
连续 supported-frame temporal flicker。
```

这一协议能够暴露“低泄漏只是因为几乎没有编辑”“小部件无法达到目标强度”“均值被近零分母放大”等常见假象。它与方法创新相符，也可作为论文独立贡献，但应定位成 edit reliability evaluation，而不是新的 segmentation benchmark。

### 21.4 与相关工作的当前边界

相对 Gaussian Grouping、SG-GS 和 GaussianEditor，当前差异仍应限定为：

```text
动态 Avatar canonical primitives 上的持久全身部件资产；
将 noisy semantics 转换为 risk-controlled edit weights；
显式联合报告 leakage、retention、coverage 和 animation behavior。
```

目前没有完成这些外部方法在同一五主体协议下的可执行对比，因此不能宣称公开方法 SOTA。内部 B0-B4/A0-A6 消融能够证明组件有效，但不能替代全部外部 baseline。

```text
baseline 复制 -> 独立 B1/B2/B3/B4；
无消融 -> A0-A6 + 微消融；
只有 recolor -> recolor/removal/texture；
无动画证据 -> 570-frame x 五主体 + 15 videos；
不稳定 ratio -> pooled burden + coverage constraint。
```

### 22.2 主会版本仍缺的决定性内容

当前仍不建议直接写成“完成的主会强稿”，主要因为：

```text
1. 三类真实编辑的正式表尚未应用跨主体 80% coverage eligibility；
2. 时序 flicker 是明确负结果，尚未拆分 semantic drift 与 strength compensation；
3. face/skin/shoes 覆盖不足，方法当前主要稳定支持 hair/upper，lower 也存在主体失败；
4. 尚无同协议外部方法定量对比；
5. 当前五个 test subject 均已被查看，缺少新的 untouched confirmation subject；
6. 复杂度、完整 reconstruction 表、最终论文图和正文尚未冻结。
```

当前最准确的投稿判断是：

```text
方法和严格内部证据已经成型；
是否够主会，取决于覆盖约束后的真实编辑主表、外部 baseline 和如何处理时序负结果；
不是再训练更多 CoreView_377 checkpoint 能解决的问题。
```

## 24. 2026-07-27 最终交接判断

当前项目的创新点与实验结果是相符的，但需要把主张收窄到证据真正支持的范围：

```text
Persistent canonical semantic asset
+ evidence-calibrated edit reliability
+ coverage-aware matched-retention evaluation
= 五主体上可验证的空间低泄漏语义编辑。
```

当前最强结论不是“所有部位、所有姿态都稳定”，而是：

```text
在统一 LOSO 协议和相同目标编辑量下，
A5 对五主体稳定降低空间 leakage；
该收益扩展到 recolor、removal 和 texture 的可达记录；
同时覆盖率约束和连续时序实验明确暴露了小部件与 flicker 局限。
```

下一步不要启动新的 CoreView_377 长训练。先完成三类真实编辑的 pooled/coverage-constrained 正式表和 fixed-vs-adaptive 时序诊断，然后冻结摘要数字、外部 baseline 和论文图。完成 P0 后即可开始完整正文；完成 P1 后再判断主会投稿还是先投 workshop/技术报告。
