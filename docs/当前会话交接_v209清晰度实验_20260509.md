## 3. 当前根因判断

目前清晰度瓶颈基本不在简单 loss 权重，而在：

```text
1. 多视角高频被 shared canonical texture 平均掉；
2. 局部高频缺少可靠 region owner / visibility gate；
3. view-conflict residual 单独开小分支不够稳定；
4. parser/Hulk 当前只能做 ROI 或 analysis，不能直接写进绑定；
5. late-stage 小修只能做指标级改善，不能提高表达上限。
```

一句话：

```text
清晰度主要卡在“局部高频由谁负责、哪些视角可信、哪些 region 能接收高频”。
```

```text

```

当前 parser 只能低风险使用：

```text

```

StageC：

```text

现在还不到 StageC。
```
