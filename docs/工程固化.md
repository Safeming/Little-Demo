# 工程固化记录

## 正式推理路径

当前正式采用的是 377 no-train signed geometry v338 grow-only guard：

```text
render.py
++explicit_binding_render_preset=v338_temporal_selector_grow_only_guard
```

对应资产：

```text
assets/adopted_geometry/377/manifest.json
assets/adopted_geometry/377/v320_selected_components.csv
assets/adopted_geometry/377/v304_point_contributors_all.csv
assets/adopted_geometry/377/v338_temporal_selector_grow_only_guard.json
```

该路径只固化 no-train inference/render/export，不采用 v321/v322/v323/v331 等 color/SH/converter/texture 训练 ckpt。
v338 在 v320/v307 formal component asset 上叠加 per-image signed point field，
其中 grow-only guard 用来阻断 temporal shrink 带来的 inner/opacity 回退。

## 正式入口

优先使用：

```text
tools/formal/run_377_signed_geometry_render.sh
tools/formal/run_377_signed_geometry_export.sh
tools/formal/run_377_v338_mainline.sh
tools/formal/run_377_v338_raw_contour_gate.sh
```

这个入口会统一传入：

```text
++explicit_binding_render_preset=v338_temporal_selector_grow_only_guard
++render_export_refine=false
dataset.subject=CoreView_377
```

并依赖 `utils/adopted_geometry.py` 对正式资产做 subject、schema、row count、sha256 校验。

`tools/run_377_formal_signed_geometry_render.sh` 和
`tools/run_377_formal_signed_geometry_export.sh` 只作为兼容 wrapper 保留。

## 训练入口

当前只允许在固定 v338 geometry 上做语义资产蒸馏：

```text
tools/formal/run_377_v338_semantic_train.sh
```

该入口会启用 `opt.stageB_semantic_adapter_only_train=true`，训练时只开放
`semantic_asset_region_logits_lr` / `semantic_asset_compact_logits_lr` 和 semantic asset adapter reg；
position、opacity、scale、rotation、SH/feature、converter、texture、camera、boundary residual
LR 全部归零，所有非 semantic-adapter 的 `lambda_*` 也会在 `train.py` 内被清零。

legacy `semantic_logits_adapter` 仍服务 texture/render 旧链路，不作为该入口的训练对象。
训练 resume 必须保留 boundary tags / binding state，否则会改变 boundary residual support，
导致 raw RGB contour gate 被无关状态扰动。
训练入口会显式打开 body-cloth 与 compact parser supervision，避免继承旧 v271 配置里
`stageB_semantic_body_cloth_weight=0`、`stageB_semantic_compact_weight=0` 的探针设置。
默认 compact mapping 是 `configs/semantic/hulk_cihp_compact_6.json`，否则 compact head loss
不会生效。

训练后必须用 raw contour gate 验证：

```text
CANDIDATE_CKPT=/path/to/ckpt.pth tools/formal/run_377_v338_raw_contour_gate.sh
```

当前主线一键入口：

```text
tools/formal/run_377_v338_mainline.sh
```

该入口串联 semantic asset adapter train -> candidate raw contour gate -> semantic editable
asset export。只有 candidate gate 返回 `strict_pass` 才会继续导出，并会调用
`tools/check_semantic_editable_assets.py` 检查 `meta.json`、`view_records.json`、
`appearance_bank.json`、`motion_bank.npz`、preview、parser preview、compact head masks。
`TRAIN_STEPS` 是从 base checkpoint 继续追加的本地训练步数；`train.py` 通过
`resume.use_checkpoint_iteration_as_offset=true` 保持保存的 ckpt iteration 与 base offset 对齐。

## 实验代码处理策略

当前先不删除历史实验脚本和训练分支。它们仍然承担实验可追溯作用，但不再作为正式入口。

推荐后续整理顺序：

```text
1. formal 入口和 asset 校验稳定后，把 v2xx/v3xx 实验脚本移动到 tools/archive/stageB_exp/。
2. 把 train.py 中 boundary/raw-support/teacher-distill/semantic loss 拆到 losses/。
3. 把 scene/gaussian_model.py 中 signed covariance、center offset、color grad protect 拆到独立 helper。
4. 删除明确 rejected 且不再被任何正式脚本引用的实验分支。
```

## 采用门槛

任何新的修边策略必须先跑 raw contour gate：

```text
fg, boundary, edge, inner, outer, hard, opacity_inner, opacity_outer
全项不能比 baseline 或当前 formal selected 变差。
```

训练颜色、SH、converter、texture 不能作为修边主线，只允许在远离 boundary/raw-support 的 interior 区域做 polish。
